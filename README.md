# 🧱 بلوك آرينا

لعبة تكسير بلوكات أونلاين مع صانع مابات، أيتمز بكود مخصص، وتحديات مع أصحابك.

## التشغيل

```bash
npm install
npm start
```

افتح http://localhost:3000

## الأقسام
- **الساندبوكس**: كل المابات المرفوعة — العب سولو، أو سوّ تحدي خاص أو لوبي عام بأي ماب.
- **صانع المابات**: بلوك رصاصي مانع، ألوان، تعبئة، مستطيل، تراجع (Ctrl+Z)، تحويل صورة لماب، تصدير/استيراد JSON، وتختار الأيتمز اللي تنزل ونسبتها.
- **مختبر الأيتمز**: ارسم الأيقونة أو ارفعها، واكتب سلوك الأيتم بـ JavaScript (`api.multiplyBalls(3)` …). القائمة الكاملة داخل الصفحة.
- **المضرب**: اسمك، لون المضرب، وتكستشر ترسمه أو ترفعه.
- **أونلاين**: غرفة خاصة برابط دعوة (`/?room=CODE`) أو لوبي عام. كل لاعب يلعب نفس الماب، وتشوف بورد الباقين لايف، والنتايج بالترتيب: اللي خلّص ← السكور ← الوقت.

## البيانات
المابات والأيتمز تنحفظ في `data/maps.json` و `data/items.json`.

## 🔒 عزل كود الأيتمز
كود الأيتمز يشتغل داخل Web Worker معزول (`public/item-worker.js`):
- ما يقدر يوصل للصفحة أو `localStorage` أو الكوكيز.
- `fetch` و `WebSocket` و `importScripts` و `indexedDB` وغيرها ممسوحة قبل ما يشتغل أي كود.
- يشوف بس نسخة من حالة اللعبة، ويرسل أوامر من قائمة محددة. اللعبة تتحقق منها قبل ما تطبقها.
- لو أي تشغيل طوّل أكثر من 400ms (لوب لا نهائي) ينقتل الـ Worker ويتوقف الأيتم.

الكود الخبيث يقدر بس يخرب الجولة حقته (يكثر الكور مثلاً)، وما يقدر يوصل لأي شي برا اللعبة.

## النشر أونلاين (Render + Supabase، مجاناً)

**1) قاعدة البيانات (عشان المابات ما تنمسح):**
1. سجّل في https://supabase.com وسوّ مشروع جديد (احفظ كلمة سر الداتابيس).
2. اضغط **Connect** فوق، وانسخ رابط **Session pooler** (يبدأ بـ `postgresql://postgres.xxxx:...@aws-...pooler.supabase.com:5432/postgres`).
3. حط كلمة السر مكان `[YOUR-PASSWORD]`.

**2) GitHub:** سوّ ريبو جديد فاضي، وبعدين من مجلد اللعبة:
```bash
git remote add origin https://github.com/USERNAME/block-arena.git
git push -u origin main
```

**3) Render:**
1. سجّل في https://render.com بحساب GitHub.
2. **New → Blueprint** واختار الريبو (يقرأ `render.yaml` تلقائياً).
3. لما يطلب `DATABASE_URL` الصق رابط Supabase واضغط **Apply**.
4. بعد دقايق يعطيك رابط ثابت مثل `https://block-arena.onrender.com`.

أي `git push` بعدها ينشر التحديث تلقائياً.

> السيرفر المجاني في Render ينام بعد 15 دقيقة بدون زوار، وأول دخول بعدها ياخذ تقريباً دقيقة.
> بدون `DATABASE_URL` اللعبة تشتغل عادي بس تحفظ في ملفات تنمسح مع كل إعادة تشغيل.
